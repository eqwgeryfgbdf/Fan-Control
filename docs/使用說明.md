# 風扇管理 Fan Control 使用說明

開啟 `/Users/server/Applications/風扇管理 Fan Control.app` 即可監測。選單列的風扇項目顯示轉速與 CPU 溫度，點開可查看 GPU 溫度及快速控制。主視窗提供 1、5、15 分鐘圖表；關閉主視窗後 App 仍會留在選單列。

v1.0.2（build 4）在頂端選單列加入迷你轉速走勢；展開後可查看最近一分鐘的實際 RPM 曲線與範圍。圖表每秒更新，主視窗按「暫停圖表」時，選單列走勢仍會繼續更新。沒有讀值的區間會留白，剛開啟 App 時只顯示已收集的資料。

在設定的「顯示與感測器」可以關閉「選單列顯示迷你走勢圖」，保留原本較精簡的圖示與數字。請從 [v1.0.2 Release](https://github.com/eqwgeryfgbdf/MacminiContoral/releases/tag/v1.0.2) 下載含圖表功能的安裝檔；私有倉庫需要登入有權限的 GitHub 帳號。

監測功能不需要管理員授權。首次啟用手動調速時，需要允許已簽署的控制服務；App 不會收集或儲存管理員密碼。

之後要啟用調速時：

1. 在控制面板或設定按「啟用風扇控制」；若等待授權，按「開啟系統設定」。
2. 於「系統設定 → 一般 → 登入項目與延伸功能」允許「風扇管理 Fan Control」，並自行完成 macOS 要求的管理員驗證。
3. 回到 App，選「手動」，選擇硬體範圍內的目標轉速，再按「套用轉速」。
4. 「目標轉速」與目前實測 RPM 分開顯示；要交回 macOS 管理，按「恢復自動調節」。

v1.0.1 已在本機 M4 Mac mini 驗證 1,500／2,000 RPM、降速及恢復自動。若硬體拒絕寫入，App 會顯示錯誤；請勿把未套用的目標值當成實際轉速。

更新舊版時，先恢復自動並結束 App。v1.0.2 已更名，請先移除 Applications 中舊的 `Macmini contoral.app`，再將 DMG 內的「風扇管理 Fan Control.app」拖至 Applications，避免保留兩份相同 App。從安裝位置開啟新版，在設定按「重新啟動控制服務」載入修正後的輔助程式；若 macOS 再次要求允許，請依系統提示完成。此版本仍使用 Apple Development 簽署，尚未經 Apple 公證。

溫度是目前可讀取的 CPU／GPU 感測器平均，不是機殼或室溫。資料無法取得時顯示「—」。圖表只保留本次執行期間最多 15 分鐘的記憶體資料，不會上傳。

最低系統版本為 macOS 15；macOS 26 以上於控制區使用 Liquid Glass。較早系統採標準材質，開啟「降低透明度」時使用不透明背景。
