# Macmini contoral 使用說明

開啟 `/Users/server/Applications/Macmini contoral.app` 即可監測。選單列的風扇項目顯示轉速與 CPU 溫度，點開可查看 GPU 溫度及快速控制。主視窗提供 1、5、15 分鐘圖表；關閉主視窗後 App 仍會留在選單列。

目前不需要進行管理員授權。監測功能已可使用，風扇維持 macOS 自動管理。

之後要啟用調速時：

1. 在控制面板或設定按「前往系統設定允許」。
2. 於「系統設定 → 一般 → 登入項目與延伸功能」允許 Macmini contoral，並自行完成 macOS 要求的管理員驗證。
3. 回到 App，選「手動」，選擇硬體範圍內的目標轉速，再按「套用轉速」。
4. 「目標轉速」與目前實測 RPM 分開顯示；要交回 macOS 管理，按「恢復自動調節」。

調速與恢復仍需在授權後進行首次實機驗證。若硬體拒絕寫入，App 會顯示錯誤；請勿把未套用的目標值當成實際轉速。

溫度是目前可讀取的 CPU／GPU 感測器平均，不是機殼或室溫。資料無法取得時顯示「—」。圖表只保留本次執行期間最多 15 分鐘的記憶體資料，不會上傳。

最低系統版本為 macOS 15；macOS 26 以上於控制區使用 Liquid Glass。較早系統採標準材質，開啟「降低透明度」時使用不透明背景。
