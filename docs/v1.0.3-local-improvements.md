# v1.0.3 本地改善紀錄

日期：2026-10-26（Asia/Taipei）。這是本地開發紀錄，尚未發布 GitHub Release。

## 控制服務讀值保護

- 控制服務自行每秒檢查所有正在控制的風扇，不依賴 App 的心跳來判定感測器是否健康。
- 風扇讀值、硬體模式或原本可讀的 CPU／GPU 溫度持續失效三秒時，撤銷手動控制並恢復自動；短暫失敗後恢復有效讀值會重新計時。
- 原本不支援的溫度感測器不會單獨阻擋手動控制；曾在手動期間取得有效讀值的溫度種類會納入監測。
- 恢復失敗時保留控制日誌、撤銷舊連線的心跳續期，持續重試；未完成恢復前拒絕新的手動控制。
- 將服務的連線擁有權、心跳、熱狀態與讀值檢查抽成可測試的共用邏輯。

驗證：25 項測試通過，其中新增 8 項服務行為測試，涵蓋持續／短暫讀值失效、溫度支援差異、多風扇、熱狀態、逾時、連線隔離及恢復失敗後重試。這些使用模擬硬體，未對實機注入過熱或感測器故障。紀錄：`dist/tests-v1.0.3-safety.log`。
